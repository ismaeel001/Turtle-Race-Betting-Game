# 🐢 Turtle Race - Betting Game

A fun and interactive turtle race simulation built with Python's `turtle` module. Place your bet on a colored turtle and watch the race unfold — will your pick win?

## 📋 Description

This project simulates a race between 6 turtles of different colors. Before the race starts, the user is prompted to bet on which colored turtle they think will win. Each turtle moves forward by a random distance in every round, making the race unpredictable. The first turtle to cross the finish line wins, and the program tells you whether your bet was correct.

## ✨ Features

- Interactive user input to place a bet before the race
- 6 turtles racing simultaneously, each in a different lane and color
- Random movement logic for realistic, unpredictable race outcomes
- Automatic winner detection once a turtle crosses the finish line
- Win/lose message based on the user's bet

## 🛠️ Built With

- **Python 3**
- `turtle` module (built-in graphics library)
- `random` module (for generating race movement)

## 🚀 How to Run

1. Clone this repository:
```bash
   git clone https://github.com/your-username/turtle-race-game.git
```
2. Navigate to the project folder:
```bash
   cd turtle-race-game
```
3. Run the script:
```bash
   python main.py
```
4. Enter a color when prompted (e.g., `red`, `blue`, `green`, `yellow`, `pink`, `navy`) and watch the race!

## 🎮 How It Works

1. A screen window opens and 6 turtles line up at the starting position.
2. You're asked to type in the color of the turtle you think will win.
3. The race begins — each turtle moves forward by a random distance every round.
4. As soon as a turtle crosses the finish line, the race stops and the result is printed in the console.
